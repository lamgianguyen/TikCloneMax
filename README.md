# TikFinity Clone

Runtime chinh cua project nay la `.NET backend` trong `backend/Program.cs`.

## Chay web

- Dung `start_project.bat`
- Hoac chay `npm run web`
- Web local mac dinh o `http://localhost:5285`

## Chay desktop

- Dung `start_desktop.bat`
- Hoac chay `npm run desktop`
- Electron se dung cung backend `.NET` nhu ban web

## Legacy runtime

- `start_server.js` duoc giu lai chi de tham khao/legacy
- Khong xem `start_server.js` la entrypoint chinh nua
